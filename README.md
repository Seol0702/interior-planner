# 3D 인테리어 플래너

실측 평면도를 바탕으로 집을 만들고, 회로 설계 프로그램 KiCad에서 부품을 꺼내 쓰듯 **가구 라이브러리에서 가구를 골라 배치**하는 웹 3D 인테리어 도구입니다.

**👉 바로 써 보기: https://seol0702.github.io/interior-planner/**

> 🚧 개발 중입니다. 계획안의 단계 순서에 얽매이지 않고 필요한 기능부터 붙이고 있습니다.

## 지금 되는 것

**방 · 구조**
- 2D 평면도에서 직사각형 방을 여러 개 추가하고 크기(m)를 입력 → 3D로 바로 반영
- 맞닿은 방 사이에는 벽이 생기고, "벽 없이 잇기"를 켜면 하나의 공간으로 이어짐 (ㄱ자 방 등)
- 문·창문을 벽에 달면 3D 벽에 실제로 구멍이 뚫림. 2D에서 끌면 가까운 벽에 붙음
- 3D에서 문·창문·콘센트를 끌면 벽을 따라 옆으로·위아래로 이동, 방향키로 1cm씩 조절

**라이브러리 (가구 · 벽지 · 장판 · 문창문 · 전기)**
- 가구 168종: 스탠바이미형 이동식 TV, 카우치 소파, 빈백, 큐브 선반(칼락스형), 모션데스크, 행거,
  2층 침대, 싱크대, 욕조·변기·세면대, 아기 침대, 러닝머신 등
  집꾸미기 콘텐츠에서 자주 보이는 가구 위주. 모두 실제 모양으로 조립되는 파라메트릭 모델
- 가구 검색, 분류 필터
- 벽지 14종 + 장판 9종, 무늬·색·크기를 바꾸는 "직접 디자인"
- 가구 사진을 올리면 대표 색 2가지를 뽑아 본체·포인트 색에 반영
- 콘센트(벽), 멀티탭(바닥), 전선 그리기

**배치**
- 드래그 이동 (벽을 통과하지 않음), `R` 회전, `Delete` 삭제, 복제
- 배치한 가구마다 폭·깊이·높이를 따로 조절 (원래 크기로 되돌리기 가능)
- 방향키 1cm · `Shift`+방향키 10cm 미세 이동
- 스마트 가이드: 다른 가구와 줄이 맞거나 간격이 같아지는 자리에 붙고 안내선 표시

**배치 규칙 검사** (KiCad의 DRC 응용, 자동 실행)
- 가구 겹침, 문 열림 충돌, 창문·콘센트 가림, 좁은 틈, 문 앞을 지나는 전선, 문 없는 방

**햇빛 · 조명**
- 반원 위의 해를 끌어 시각을 바꾸면 창문으로 드는 햇빛과 그림자가 바뀜 (계절·방위 선택, 하루 재생)
- 창으로 들어오는 빛줄기와 바깥 땅의 집 그림자를 3D로 표시
- 방별로 햇빛이 드는 넓이(㎡, %) 표시, 2D 평면도에도 햇빛 자리 표시
- 창문이 없으면 알려 주고 한 번에 창문 달기
- 밤 보기 + 실내 조명(플로어 램프·천장등) 켜기

**화면**
- 왼쪽 메뉴(방·가구·벽지·문창문·전기·햇빛·창밖·검사·메모·추천) → 패널 → 화면의 3단 구성
- 가구 목록은 실제 3D 모델을 찍은 미리보기 그림으로 표시
- 나침반: 시점을 돌려도 항상 북쪽을 가리킴
- 레이어 보기: 전체 / 가구 / 전기 / 구조 (`V` 키로 전환)
- 시점: 왼쪽 드래그 이동, 오른쪽 드래그 회전, 휠 확대·축소, 바로가기(입체·위·0°·90°·180°·270°)
- 3D / 2D 평면도 / 나란히 보기

**걷기 (1인칭 · 3인칭)**
- 화면 아래 `걷기`를 누르면 사람 눈높이로 집 안을 걸어 다님. `C` 키로 1인칭 ↔ 3인칭(사람 모형) 전환
- 키 170cm 기준 눈높이 158cm · 몸 폭 46cm (키를 바꾸면 함께 바뀜, 한국 20~30대 남성 평균 비율)
- 벽과 가구에 부딪히고, 몸 폭보다 좁은 가구 틈은 지나가지 못함. 문은 열린 채로 지나감
- 조작: `W A S D`·`↑↓` 걷기, `← →` 돌기, 드래그 둘러보기, `Shift` 빨리, 휠 3인칭 거리. 터치 화면에는 방향 단추

**창밖 풍경**
- 지도를 누르거나, 주소·아파트 이름으로 찾거나, 구글·네이버 지도 링크/좌표를 붙여 넣어 집 위치 지정
- 그 위치 주변 400m의 실제 건물(OpenStreetMap 모양·높이)과 Esri 위성사진 땅을 3D로 세움
- 층수를 넣으면 그 높이에서 보이는 창밖, 지도 위 집 모양을 돌려 실제 방향(방위) 맞추기

**메모 · 추천**
- 원하는 자리에 메모 점을 찍고, 누르면 내용 표시. 전체 펼치기·숨기기
- 지금 집의 평수로 유튜브·오늘의집·핀터레스트 등 검색 결과 바로 열기

**저장**
- JSON 파일 저장/불러오기 + 브라우저 자동 저장 (예전 버전 파일은 자동 변환)

## 아직 안 되는 것
- 건축물대장(건축HUB) API로 면적 불러오기: API 키 발급 + 서버리스 함수가 필요
- 추천 자료를 앱 안에서 바로 보여주기 (지금은 검색 결과 페이지를 새 창으로 엶)
- 사진에서 가구 "모양"까지 인식하기 (지금은 색만 반영)
- 햇빛 계산은 서울 위도 기준의 근사값이며, 이웃 건물의 그늘은 반영하지 않음
- 창밖 풍경은 사진이 아닌 모형. 높이 정보가 없는 건물은 3층으로 짐작하고, 지형(언덕)은 반영하지 않음

## 기술 스택
- TypeScript + React (Vite)
- 3D: three.js, react-three-fiber, drei
- 지도: Leaflet + OpenStreetMap, 건물: OpenFreeMap 벡터 타일(예비로 Overpass API), 위성사진: Esri World Imagery

## 실행 방법
```bash
npm install
npm run dev
```
실행한 뒤 브라우저에서 http://localhost:5173 을 엽니다.
