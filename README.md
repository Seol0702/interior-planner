# 3D 인테리어 플래너

실측 평면도를 바탕으로 집을 만들고, 회로 설계 프로그램 KiCad에서 부품을 꺼내 쓰듯 **가구 라이브러리에서 가구를 골라 배치**하는 웹 3D 인테리어 도구입니다.

> 🚧 개발 중. 1단계(MVP)를 마치고 2·3단계 기능을 붙이는 중입니다.

## 지금 되는 것

**방**
- 2D 평면도에서 직사각형 방을 여러 개 추가하고 크기(m)를 입력 → 3D로 바로 반영
- 방을 끌어서 옮기면 옆방 모서리에 착 붙고, 맞닿은 방은 하나의 공간으로 이어짐 (ㄱ자 방 등)
- 방 목록은 평소 이름·평수만 보이고, 누르면 크기 입력칸이 펼쳐짐

**라이브러리 (가구 · 벽지 · 장판)**
- 가구 22종: 의자·소파·침대·책장 등 실제 모양으로 조립되는 파라메트릭 모델
- 가구 검색, 분류(거실·침실·서재·주방·가전) 필터
- 벽지 14종 + 장판 9종, 무늬·색·크기를 바꾸는 "직접 디자인"
- 가구 사진을 올리면 대표 색 2가지를 뽑아 본체·포인트 색에 반영

**배치**
- 드래그 이동 (벽 밖으로 나가지 않음), `R` 회전, `Delete` 삭제, 복제
- 방향키 1cm · `Shift`+방향키 10cm 미세 이동 (3D에서는 보는 방향 기준)
- 스마트 가이드: 다른 가구와 줄이 맞거나 간격이 같아지는 자리에 붙고 안내선 표시

**시점**
- 왼쪽 드래그 = 시점 이동, 오른쪽 드래그(또는 Ctrl+드래그) = 회전, 휠 = 확대/축소
- 시점 바로가기: 입체 · 위 · 0° · 90° · 180° · 270°
- 3D / 2D 평면도 / 나란히 보기, 카메라 쪽 벽 자동 숨김

**저장**
- JSON 파일 저장/불러오기 + 브라우저 자동 저장

## 아직 안 되는 것
- 건축물대장(건축HUB) API로 면적 불러오기: API 키 발급 + 서버리스 함수가 필요해 다음 단계에서 진행
- 사진에서 가구 "모양"까지 인식하기 (지금은 색만 반영)
- 문·창문, 방 사이 벽, 가구 겹침 경고

## 기술 스택
- TypeScript + React (Vite)
- 3D: three.js, react-three-fiber, drei

## 실행 방법
```bash
npm install
npm run dev
```
실행한 뒤 브라우저에서 http://localhost:5173 을 엽니다.
